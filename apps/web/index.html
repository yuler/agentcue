How it works

  1. Activate — Press Cmd/Ctrl + Shift + F (or click the ✦ launcher) to open the toolbar and enter Pick Mode.
  2. Pick & annotate — Click elements to drop numbered Pins. Type a change note for each, press Enter to save and pick more.
  3. Push Cue — Press S or Cmd/Ctrl + Enter to send all Pins as a structured Cue to your Agent CLI. Code edits and HMR reload automatically.

Keyboard shortcuts

Shortcut Action
Cmd/Ctrl + Shift + F Activate / collapse toolbar + toggle Pick Mode
Enter Save current Pin, stay in Pick Mode
S / Cmd/Ctrl + Enter Send all Pins as a Cue
P Pause / resume Pick Mode
A / 1-5 Switch Agent Target
R Reset current Agent session
C Copy Cue as Markdown
X Clear all Pins
H Hide / show Pins
Esc Close popover or collapse toolbar
